<h1>Glass BIO</h1>
A basic single page about me site, that has all your links. Heavily inspired by the website ez.bio (https://e-z.bio/). The visual style of the site was inspired by the modern ui design trend glassmorphism. It was made for learning purposes. <br><br>
In the main branch the page is made with minimal placeholders, while in the example branch you can see how it would look if used.
<br><br>
I would love to see what have you achieved with this, so if you use this please send me the results! I am also open to fixes.<br><br>
**P.S.** Keep in mind you can host this for free on github pages.
